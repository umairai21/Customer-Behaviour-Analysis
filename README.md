# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, PostgreSQL, and Power BI. The goal of the project was to analyze a dataset, extract meaningful insights, and present the findings through interactive dashboards and reports.

The project includes:

- Data loading and preprocessing using Python
- Exploratory Data Analysis (EDA)
- Data cleaning and transformation
- SQL analysis using PostgreSQL
- Interactive dashboard creation in Power BI
- Business insights reporting
- Presentation creation using Gamma AI

---

## Dataset

The dataset used in this project contains structured data related to business operations and performance analysis.

### Dataset Features

- Multiple attributes and records for analysis
- Missing values and inconsistencies handled during cleaning
- Suitable for trend analysis, KPI tracking, and visualization

## Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas
- Inspected data structure and data types

### 2. Exploratory Data Analysis (EDA)
- Analyzed distributions and trends
- Identified missing values and outliers
- Generated visualizations for better understanding

### 3. Data Cleaning
- Removed duplicates
- Handled missing/null values
- Standardized and transformed columns
- Prepared data for analysis and visualization

### 4. SQL Analysis with PostgreSQL
- Imported cleaned dataset into PostgreSQL
- Wrote SQL queries for:
  - Aggregations
  - Filtering
  - Grouping
  - KPI calculations
  - Trend analysis

### 5. Power BI Dashboard
- Built an interactive dashboard to visualize insights
- Included charts, KPIs, filters, and trend analysis
- Designed for easy business interpretation

### 6. Reporting & Presentation
- Created a detailed analytics report
- Generated a presentation using Gamma AI to summarize findings and recommendations

## How to Run the Project

### 1. Clone the Repository

```bash
git clone <repository-link>
```

### 2. Install Required Libraries

```bash
pip install pandas matplotlib seaborn psycopg2
```

### 3. Run the Jupyter Notebook

```bash
jupyter notebook
```

### 4. Connect PostgreSQL

- Create a PostgreSQL database
- Import the cleaned dataset
- Run the SQL queries from the `/sql` folder

### 5. Open Power BI Dashboard

- Open the `.pbix` file in Power BI Desktop
- Refresh the data connection if required
